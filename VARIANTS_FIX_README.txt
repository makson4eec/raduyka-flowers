РАДУЙКА — ФИНАЛЬНОЕ ИСПРАВЛЕНИЕ ВАРИАНТОВ ЦВЕТОВ

Что исправлено:
1. Один товар = одно название (например «Лилия», «Гипсофила»).
2. Цвета выбираются внутри карточки товара.
3. У каждого цвета своё фото и своя цена.
4. Под главным фото показываются миниатюры всех вариантов.
5. Кнопка «+» у товара с несколькими цветами сначала открывает карточку, чтобы покупатель выбрал цвет.
6. Выбранный вариант передаётся в корзину и заказ.
7. API заказов принимает variantId.
8. В админке варианты доступны для ЛЮБОГО товара типа «Цветы поштучно».
9. SQL исправляет старые названия «Лилии белые», «Лилии розовые», «Гипсофилы Радужные», «Гипсофилы Белые» и их варианты написания.

После замены файлов:
1. В Supabase SQL Editor запустить целиком: supabase/fix-flower-variants.sql
2. Перезапустить проект: npm.cmd run dev
3. Открыть localhost:3000 и сделать Ctrl+F5.

Важно: старый flowers.sql тоже исправлен, чтобы повторный запуск не создавал снова отдельные карточки лилий/гипсофилы.
