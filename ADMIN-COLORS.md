# Цветовые варианты через админку

Для добавления и изменения цветов Supabase SQL Editor больше не нужен.

1. Откройте `/admin` → **Товары**.
2. Создайте **Цветы поштучно** или нажмите **Изменить** у существующего цветка.
3. В блоке **Цвета в карточке** нажмите **Добавить цвет**.
4. Для каждого цвета укажите название, цену и загрузите отдельное фото.
5. Первый вариант считается основным: его фото и цена используются на карточке в каталоге. Другой вариант можно сделать основным кнопкой **Сделать основным**.
6. Нажмите **Сохранить товар**.

После сохранения варианты записываются через защищённый admin API в поле `products.variants`. На витрине посетитель увидит выбор цвета, а выбранный вариант попадёт в корзину и заказ.

Ограничение: не более 12 цветов в одной карточке.
