РАДУЙКА — варианты цветов

1. Замените файлы проекта содержимым этого архива.
2. В Supabase SQL Editor откройте файл supabase/fix-flower-variants.sql, скопируйте его целиком и нажмите Run.
   Этот SQL НЕ удаляет товары: старые дубли Лилии/Гипсофилы только скрываются с витрины.
3. Перезапустите локальный сайт: npm.cmd run dev
4. Откройте /admin.

Для Лилии и Гипсофилы уже появятся варианты цвета внутри одной карточки.
Для ЛЮБОГО другого цветка:
- откройте товар в админке;
- убедитесь, что раздел = «Цветы поштучно»;
- оставьте в поле «Название» только общее название (например «Гербера»);
- в блоке «Цвета в карточке» нажмите «+ Добавить цвет»;
- для каждого цвета укажите название, цену и загрузите отдельное фото;
- сохраните товар.

На витрине покупатель увидит одну карточку товара и выбор цвета внутри неё.
Выбранный цвет, фото и цена передаются в корзину и заказ.
